# Computational Fluid Dynamics (CFD)

This repository contains MATLAB implementations of basic numerical methods, finite difference schemes, and computational solvers developed for the introductory *Computational Fluid Dynamics* coursework at the National Technical University of Athens (NTUA). 

The repository is structured into distinct Problem Sets, progressing from fundamental linear algebra solvers to complex fluid and heat transfer simulations.

## Repository Structure

* **`Problem_Set_1/`**: Direct and iterative solvers for linear systems ($Ax=b$) and non-linear roots ($F(x)=0$). Includes Thomas Algorithm, Jacobi, Gauss-Seidel, Successive Over-Relaxation (SOR), and Newton-Raphson methods.
